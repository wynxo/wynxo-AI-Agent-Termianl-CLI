🚀 HOW TO USE THE KAWAII FEATURES:

1. Set your theme in config.json:
   {
     "theme": "catboy"
   }

2. In code, import and use effects:
   from wynxo.kawaii_effects import sparkle_text, catboy_reaction
   
   message = sparkle_text("Operation successful!")
   reaction = catboy_reaction("Let's go~")

3. Available in Pet animations automatically when using kawaii style
